Purpose of This Document

This is a rebuild spec for the GraderInsight web application. The current MVP has pages and features that don't align with the product's actual architecture. Use this document to modify the existing Replit codebase — removing pages that don't belong, restructuring the ones that stay, and adding new components where needed.

Architecture Context (Read First)

GraderInsight is a two-part system:

Desktop App (Python/tkinter) — Installed locally on the educator's computer. This is where all grading happens. Educators download assignments from their LMS (D2L, Canvas, Blackboard, Moodle), import files into the desktop app, configure rubric criteria, run AI-powered batch grading via the Anthropic API, review results, and export CSV reports. All student data stays on the educator's machine. Nothing is uploaded to our servers.
Web App (this Replit project) — A subscription portal and resource hub. Its job is: account management, subscription/billing, desktop app downloads, rubric template management, and onboarding guidance. It is NOT a grading tool. It does NOT receive or store student assignments.

This distinction is critical. Every page and component in the web app must serve the portal/hub role, not duplicate the desktop app's grading workflow.
